# Sécurité

Si vous découvrez une vulnérabilité ou un secret exposé, merci de contacter le propriétaire du dépôt.

Recommandations :
- Ne commitez jamais de secrets. Utilisez `.env` local et ajoutez-le à `.gitignore`.
- Configurez les *GitHub Secrets* pour les clés et tokens nécessaires.
- Activez les protections de branche, la vérification des PR et l'analyse de code si possible.
